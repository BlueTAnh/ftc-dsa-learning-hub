# DSA Learning Hub

A 10-week **Data Structures & Algorithms** course in **Python**, run by the **RMIT Vietnam FinTech Club**.

This repo holds everything you need: live-code examples, homework and solutions.

---

## Vision

- Build basic DSA knowledge in a friendly environment.
- Understand clearly how DSA theory connects to code.
- Grow motivation to keep practising problem solving and coding.

## Getting started

1. **Install Python 3** and **VSCode** — see [`setup/python-setup.md`](setup/python-setup.md).
2. **No setup?** Open any `.ipynb` file on GitHub and click **Open in Colab**.
3. **Get the code:**
   ```bash
   git clone https://github.com/BlueTAnh/ftc-dsa-learning-hub.git
   ```
   Or click **Code → Download ZIP**.
4. **Create a free [LeetCode](https://leetcode.com) account** — most homework problems are there.

## Homework

- Released at the end of each session, **due before the next session**.
